LeetCode 189 – Rotate Array

Topic: Arrays | Two Pointers

1. PROBLEM STATEMENT

Given an integer array nums, rotate the array to the right by k steps, where k is non-negative.

The rotation should be performed in-place without using extra space.

2. APPROACH – REVERSE-REVERSE (THREE REVERSALS)

- Store the array length in n.
- If the array is empty, return.
- Calculate k = k % n to handle rotations greater than the array length.
- If k = 0, no rotation is required, so return.
- Reverse the entire array.
- Reverse the first k elements.
- Reverse the remaining n-k elements.
- The array is now rotated to the right by k positions.

3. DRY RUN

Input:

nums = [1, 2, 3, 4, 5, 6, 7]
k = 3

Step 1: Reverse the entire array.

[1, 2, 3, 4, 5, 6, 7]

Becomes:

[7, 6, 5, 4, 3, 2, 1]

Step 2: Reverse the first k elements.

Reverse [7, 6, 5].

Becomes:

[5, 6, 7, 4, 3, 2, 1]

Step 3: Reverse the remaining elements.

Reverse [4, 3, 2, 1].

Becomes:

[5, 6, 7, 1, 2, 3, 4]

Output:

[5, 6, 7, 1, 2, 3, 4]

4. COMPLEXITY ANALYSIS

Time Complexity: O(n)

The array is traversed through three reverse operations. Each reversal takes linear time.

Space Complexity: O(1)

The array is modified in-place using only one temporary variable.

5. KEY INTERVIEW POINTS

1. Why use k = k % n?
Because rotating an array n times brings it back to its original position.

2. Why reverse the entire array first?
To bring the last k elements to the beginning, but in reverse order.

3. Why reverse the first k elements?
To restore the original order of the elements moved to the beginning.

4. Why reverse the remaining elements?
To restore the original order of the remaining elements.

5. Why use three reversals?
To rotate the array in-place without using an extra array.

6. Why use start and end pointers?
To swap elements from both ends and reverse the array.

7. What is the difference between O(n) time and O(1) space?
We traverse the array, but use only constant extra memory.
